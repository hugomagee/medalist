# Medalist M1–M5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement SPEC.md milestones M1–M5: an autonomous ML-competition harness (bundle loading, append-only ledger, sandboxed runner, CV engine, metric registry, strategies, EDA, memory, submission, grading) proven end-to-end by a scripted dumb agent on a synthetic competition.

**Architecture:** `core/` is a typed, tested harness library; `strategies/` holds fold-safe reusable ML building blocks; the CLI (`typer`) is a thin wrapper. Experiments run as subprocesses with the `private/` dir made unreadable (anti-cheat boundary). All state (budget, memory) derives from the append-only SQLite ledger. Everything is path-parameterized so tests run in tmp dirs.

**Tech Stack:** Python 3.12 (venv+pip; uv unavailable), pandas, numpy, scikit-learn, lightgbm, xgboost, catboost, optuna, typer, jinja2, pyyaml, matplotlib, pyarrow, pytest, hypothesis, ruff, mypy (strict on core/).

**Authoritative source:** SPEC.md. On conflict, SPEC.md wins; deviations go to DECISIONS.md.

## Locked design decisions (log all in DECISIONS.md)

1. **Env:** `uv` not installed → `python3.12 -m venv .venv` + pip (spec §3 fallback).
2. **Metrics:** mae/rmse/rmsle/accuracy implemented independently in numpy and tested vs sklearn to 1e-12; auc/logloss/f1 wrap sklearn directly (sklearn *is* the reference; hand-rolled ties/eps handling can't guarantee 1e-12 agreement). Tests still assert equality vs direct sklearn calls (verifies wiring: probs vs labels).
3. **Extra modules not in spec layout:** `core/exp_driver.py` (subprocess-side of runner), `core/grading.py` (percentile/medal/RESULT.md; keeps `scoring.py` pure), `core/eda.py` (referenced by §9 but absent from §4 layout), `core/errors.py` (shared exception types).
4. **Ledger location:** single `ledger.db` at repo root (spec §3 "single file"), path always injected for testability. Gitignored.
5. **Budget state** derived entirely from ledger rows (no second store). Reserve experiments usable only via `medalist run --final`.
6. **Graveyard family** = `approach["model_family"]`; "failed" = status in {failed, timeout} OR completed with score worse than its parent. ≥2 failures → graveyard.
7. **Medal thresholds** (standard Kaggle table), rank r (1-based), n teams; pct counts use `max(1, floor(pct*n))`:
   - n ≤ 99: gold 10%, silver 20%, bronze 40%
   - 100–249: gold top 10, silver 20%, bronze 40%
   - 250–999: gold 10 + floor(0.002n), silver top 50, bronze top 100
   - n ≥ 1000: gold 10 + floor(0.002n), silver 5%, bronze 10%
8. **TimeSeriesSplit** cannot satisfy "folds partition training set exactly"; its property tests instead assert: validation folds disjoint, and every train index < every validation index within each split.
9. **Dumb agent** lives in `scripts/dumb_agent.py` (importable, called by M5 test).
10. **Predictions are 1-D** (regression values, class labels for accuracy/f1, positive-class probability for auc/logloss). Multiclass probability output is out of scope v1.
11. **Leaderboard CSV format:** must contain a `score` column, one row per team. Documented in `competitions/README.md`.
12. **MEMORY.md per competition** written to `competitions/<slug>/MEMORY.md`.
13. **Submission output:** `reports/<slug>/submission.csv` (+ provenance in `submission.json`).

    # helpers: train_path, test_path, sample_submission_path, private_dir, path_for(key)

# core/ledger.py
@dataclass(frozen=True)
class Experiment:
    exp_id: str; comp_slug: str; parent_id: str | None; hypothesis: str
    approach: dict[str, Any]; status: str
    cv_score_mean: float | None; cv_score_std: float | None
    cv_fold_scores: list[float] | None; wall_seconds: float | None
    created_at: str; finished_at: str | None
    artifact_dir: str; error: str | None; notes: str | None

class Ledger:
    def __init__(self, db_path: Path): ...
    def queue(self, comp_slug, hypothesis, approach, artifact_dir, parent_id=None) -> str

    def complete(self, exp_id, cv_score_mean, cv_score_std, cv_fold_scores, wall_seconds) -> None
    def fail(self, exp_id, error, wall_seconds, timeout=False) -> None
    def annotate(self, exp_id, notes) -> None             # notes on terminal rows only
    def get(self, exp_id) -> Experiment
    def list(self, comp_slug) -> list[Experiment]
    def best(self, comp_slug, direction) -> Experiment | None

## Milestone M2 — Runner + CV + scoring

### Task 2.1: Metric reference tests
- [ ] Extend `tests/test_scoring.py`: for random vectors (fixed seeds, several shapes incl. edge cases like all-same-class handled where defined), each registry metric equals sklearn reference (`mean_absolute_error`, `root_mean_squared_error`, `root_mean_squared_log_error`, `roc_auc_score`, `log_loss`, `accuracy_score`, `f1_score`) to `abs=1e-12`. Hypothesis property: mae/rmse ≥ 0; rmse ≥ mae never asserted (false) — instead assert metric(y,y)==0 for error metrics, accuracy(y,y)==1.
- [ ] Run → pass (or fix impls). Commit `test: metric registry vs sklearn to 1e-12`.

### Task 2.2: CV engine (`core/cv.py`)
- [ ] Unit tests for `resolve_policy`: time_column→timeseries, group_column→group, int/object target with <20 uniques→stratified, else kfold; explicit policy respected; decision includes human-readable reason.
- [ ] Hypothesis property tests over generated frames: for kfold/stratified/group — fold valid indices partition range(n) exactly, no train/valid overlap; group — no group appears in both sides of a split; timeseries — valid folds disjoint and max(train_idx) < min(valid_idx).
- [ ] `validate_alignment(n_train, n_test, oof, test_pred)`: length mismatches and NaN/inf raise RunnerError with counts in message.
- [ ] TDD; implement; commit `feat: CV policy engine with property tests`.

### Task 2.3: Budget manager (`core/budget.py`)
- [ ] Tests: defaults (25/900s/14400s/2 reserve); overrides from bundle `budget:`; status derived from a seeded ledger (used = non-queued rows count; wall = sum wall_seconds); `can_queue()` False once used ≥ max−reserve unless `final=True`; False for everyone at max; False when wall budget exhausted; `summary_line()` contains remaining counts.
- [ ] TDD; implement; commit `feat: budget manager`.

### Task 2.4: Runner + driver (`core/runner.py`, `core/exp_driver.py`)
Protocol: parent does static `private` string check on run.py → chmod private dir 0o000 (restore in `finally`) → spawns `[python, -m, core.exp_driver, cfg.json]` with `cwd=exp_dir`, timeout=per_experiment_seconds, kill on expiry. Driver: seeds (random/numpy = cv seed), loads train/test, builds splitter via core.cv, imports `run.py` by path, calls `run()`, validates keys/lengths, writes `oof.parquet`, `test_pred.parquet`, `driver_result.json`. Parent then: alignment check, computes fold scores from OOF with registered metric over materialized fold indices, writes `result.json` (+`importances.json` if given), ledger complete/fail/timeout.
- [ ] Tests (real subprocesses, small data): success path — mean-baseline run.py completes, artifacts exist, cv fields populated, status completed; run.py raising → status failed, error contains traceback tail; run.py with `time.sleep(30)` + per_experiment_seconds=2 → status timeout in <10s; run.py containing the string `private` → rejected before spawn; run.py opening the private solution path via `os.path` tricks that avoid the literal string but hit the chmod wall → subprocess PermissionError → failed; determinism — same deterministic experiment run twice, cv means equal within 1e-9; private dir permissions restored after run (even on failure).
- [ ] TDD; implement; wire `medalist run <slug> --exp <id> [--final]` and `medalist status` (ledger summary + budget line). Full suite green; mypy clean. Commit `feat: sandboxed experiment runner with timeout and anti-cheat boundary` — **M2 gate**.
